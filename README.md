# CampScan

QR-сканер для табірної гри. Камера запускається автоматично при відкритті сторінки,
постійно працює, і після кожного успішного сканування під вікном камери великим
текстом з'являється слово (або повідомлення-пустушка), зашифроване в QR-коді.

Усі дані зберігаються локально у файлі `src/data/codes.json`. Сервера, бази даних
та зовнішніх API немає.

## Стек

- React 18
- Vite 5
- TypeScript
- TailwindCSS
- html5-qrcode (читання камери)
- qrcode (генерація PNG під час створення проєкту)

## Локальний запуск

```bash
npm install
npm run dev
```

Сервер розробника буде доступний за адресою, яку виведе Vite (зазвичай
`http://localhost:5173`).

## Власна генерація

QR-коди та файл `src/data/codes.json` вже згенеровані та додані до репозиторію,
тому нічого додатково робити не потрібно. Якщо ви хочете перегенерувати коди
(нові випадкові значення), запустіть:

```bash
npm run generate
```

Скрипт:
- створює унікальні 6-символьні коди без неоднозначних символів (`0`, `O`, `1`, `I`);
- записує в `src/data/codes.json` усі слова та три пустушки;
- створює PNG QR-коди у `public/qr/words/` та `public/qr/decoys/`.

У сам QR записується лише код (не URL, не JSON, не текст слова).

## Збірка

```bash
npm run build
```

Готова статична збірка з'являється у теці `dist/`.

## Публікація на Netlify

1. Завантажте цей репозиторій на GitHub.
2. У Netlify: **Add new site → Import an existing project**, оберіть репозиторій.
3. Налаштування вже задані у `netlify.toml`:
   - Build command: `npm run build`
   - Publish directory: `dist`
4. Натисніть **Deploy**.

Або вручну через CLI:

```bash
npm install -g netlify-cli
npm run build
netlify deploy --prod --dir=dist
```

## Як працює сканування

- Камера стартує сама одразу після завантаження сторінки.
- Після сканування камера не вимикається.
- Якщо той самий QR постійно перед камерою, він не обробляється повторно.
- Повторно扫描 того самого QR стає можливим лише після того, як він
  зник з камери хоча б на одну секунду.
- Новий QR визначається миттєво.
- Білий фон, чорний текст, єдина синя кнопка з'являється лише тоді, коли
  браузер повторно просить доступ до камери.

## Сховище слів

Слова утворюють вірш з Римлян 12:21:

> Не будь переможений злом, але перемагай зло добром. Римлян 12:21

Пустушки (три окремі QR-коди) показують повідомлення:

- Пощастить наступного разу.
- Тут нічого немає.
- Спробуйте знайти інший QR-код.
